WORKSHOP MANAGER FOR MAC - READ ME FIRST
========================================

Works on Apple Silicon (M1-M4) and Intel Macs, macOS 11 or newer. Nothing else to install.


1. INSTALL
   - Double-click the zip to unzip it (if WhatsApp/Safari hasn't already).
   - Open the "Workshop Manager (Mac)" folder and drag BOTH apps into the
     Applications folder:
        Workshop Manager.app
        Workshop Manager - Sample data.app

2. FIRST START (only needed once)
   macOS blocks apps that aren't signed with a paid Apple certificate, so:
   - Double-click Workshop Manager in Applications. macOS says it can't be opened. Click Done.
   - Open System Settings > Privacy & Security, scroll down, and click "Open Anyway"
     next to Workshop Manager. Enter your Mac password if asked, then click Open.
   - Do the same once for "Workshop Manager - Sample data" if you use it.

   If "Open Anyway" doesn't appear, open the Terminal app and paste this line, then press Enter:
        xattr -dr com.apple.quarantine "/Applications/Workshop Manager.app" "/Applications/Workshop Manager - Sample data.app"
   After that both apps open normally.

3. SET UP
   - Create the admin username and password.
   - WRITE DOWN THE RECOVERY CODE and keep it safe. It's the only way back in if the
     password is forgotten.
   - A short tour and the "Getting started" list then walk you through setting up.


TRY IT WITH SAMPLE DATA
   - Open "Workshop Manager - Sample data" and log in with:  admin  /  demo123
   - Four months of a pretend workshop to practise on, kept completely separate from
     your real records.


WHERE YOUR DATA IS
   - Records (encrypted):   ~/Library/Application Support/WorkshopManager
   - Bills, reports, PDFs:  Documents/Workshop Manager
   - Backups are made every day; choose a USB or iCloud/Google Drive folder for them
     in Settings > Backup.


UPDATES
   - The app updates itself. When the Mac is online it checks for a new version every
     few hours, downloads it in the background and makes a backup of your records.
     The new version starts the next time the app is opened (or click "Restart now").
   - See or change this in Settings > Updates.
   - If a new version ever fails to start, the app goes back to the previous one by itself.
